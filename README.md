# Personal Portfolio Website

A responsive personal portfolio website built to showcase my skills, projects, experience, and journey as a web developer.

## 🚀 Overview

This project is my personal developer portfolio, designed to provide an overview of my frontend development skills and the projects I have built.

The website focuses on a clean, responsive layout and uses vanilla web technologies to create the interface and interactive functionality.

## 🛠️ Built With

* HTML5
* CSS3
* JavaScript
* Responsive Web Design

## ✨ Features

* Responsive design for desktop, tablet, and mobile devices
* Personal introduction and developer profile
* Skills and technologies section
* Project showcase
* Contact information
* Interactive elements powered by JavaScript
* Custom styling with CSS
* Image and asset integration

## 💻 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/Jabezgreenan/personal-site-js.git
```

### 2. Open the project

Navigate into the project directory:

```bash
cd personal-site-js
```

### 3. Run the website

This is a static website, so no build tools or backend server are required.

Simply open `index.html` in your browser.

For development, you can also use the **Live Server** extension in VS Code.
